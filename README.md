# Scale100x Onboarding Wizard Prototype

## Run locally
1. Install Node.js 20+.
2. Run `npm install`
3. Run `npm run dev`
4. Open the local URL printed by Vite.

## Publish
Push this folder to a GitHub repository and import it into Vercel, or deploy using your preferred React hosting provider. Build command: `npm run build`; output directory: `dist`.

## Demo limitations
- No backend, authentication, database, real AI model, or persistent file upload is connected.
- File selection stores filenames in in-memory React state only.
- Readiness score is a transparent front-end heuristic and is not a validated business score.
- The AI/Human percentage is a static assignment-provided label, not measured telemetry.
